# VLESS with TLS

VLESS with TLS uses a domain and a TLS certificate for the connection.

## Before you start

Use a domain that points to your server. Open TCP port 443.

The current Docker manager does not implement this inbound. Installation reports an error. Choose another protocol for now.

## Set up the service

This option is not ready to install through the current Docker manager. Choose another protocol until the implementation is available.

## Connect and manage

Use a compatible VLESS app when the service is available.

Keep connection credentials private.
