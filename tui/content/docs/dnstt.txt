# DNSTT

DNSTT carries traffic through DNS queries. It is a slow fallback when DNS still works.

## Before you start
Use a domain you control. Delegate a DNS name to your server and open UDP port 53.

## After installation
DNSTT needs a compatible client, the delegated name, and the server public key. It is not a one-click phone VPN.

Do not run another DNS tunnel on the same port. A network can block DNS tunnels, and DNS access alone does not guarantee a working connection.
